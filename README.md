# DIRCE Tecnologia

Site institucional da DIRCE Tecnologia, preparado para Cloudflare Workers Static Assets.

Projeto independente do ORICSE.

## Publicação

- Conectar este repositório ao Cloudflare Workers & Pages usando a integração GitHub.
- Branch de produção: `main`.
- Comando de deploy: `npx wrangler deploy`.
- Comando de build: vazio, para os arquivos estáticos em `public/`.

O site apresenta Desenvolvimento, Inovação, Resultados, Conectividade e Evolução.

Nenhum token ou senha deve ser armazenado neste repositório.
